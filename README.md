# JE Form

A form builder plugin for WordPress. Create forms in the admin, drop them on any page with a shortcode, and manage submissions from the dashboard.

## Features
- Form builder in wp-admin with per-field settings
- Standard fields (text, email, textarea, number, tel, url, date, time and more)
- E-signature field (drawn on a canvas, saved as an image)
- Special select fields
- Auto-location address field (device GPS or IP-based, reverse geocoded with OpenStreetMap)
- File upload field with allowed extensions and max size
- Honeypot spam protection and nonce-protected submissions
- HTML email notification for each submission
- Submissions list with export
- Duplicate and preview forms

## Usage
Add a form to any page or post with the shortcode:

[jeform id="1"]

## Requirements
- WordPress 5.8+
- PHP 7.4+

## Installation
1. Download the plugin zip from the Releases page.
2. Go to Plugins > Add New > Upload Plugin and upload it.
3. Activate it and open the JE Forms menu to create your first form.
